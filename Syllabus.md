# Python to Machine Learning Workshop — 20-Day Syllabus

**Duration:** 20 Days | 2 Hours/Day | Total: 40 Hours  
**Capstone Project:** End-to-End ML Pipeline (Days 17–20)

---

## Week 1: Python Fundamentals (Days 1–5)

### Day 1: Introduction & Setup

- Installing Python, VS Code/Jupyter Notebook setup
- Variables, data types, operators
- Input/output, string formatting
- **Practice:** Simple calculator program

### Day 2: Control Flow & Functions

- if/elif/else, loops (for, while)
- Functions, parameters, return values
- Scope, default arguments, \*args/\*\*kwargs
- **Practice:** Number guessing game

### Day 3: Data Structures

- Lists, tuples, sets, dictionaries
- List comprehensions
- Iterating, slicing, nested structures
- **Practice:** Student grade manager

### Day 4: File Handling & Modules

- Reading/writing files (txt, CSV)
- Exception handling (try/except)
- Importing modules, creating modules
- **Practice:** CSV data reader

### Day 5: Object-Oriented Programming

- Classes, objects, **init**
- Methods, attributes, inheritance
- Practical OOP patterns
- **Practice:** Bank account class

---

## Week 2: Data Science Stack (Days 6–10)

### Day 6: NumPy

- Arrays, shapes, dtypes
- Indexing, slicing, broadcasting
- Mathematical operations, linear algebra basics
- **Practice:** Matrix operations exercises

### Day 7: Pandas — Part 1

- Series and DataFrames
- Reading CSV/Excel files
- Selecting, filtering, sorting data
- **Practice:** Explore a real dataset

### Day 8: Pandas — Part 2

- Handling missing data
- GroupBy, aggregation, pivot tables
- Merging and joining DataFrames
- **Practice:** Sales data analysis

### Day 9: Data Visualization — Matplotlib & Seaborn

- Line plots, bar charts, histograms, scatter plots
- Subplots, labels, legends, styling
- Seaborn: heatmaps, pair plots, distribution plots
- **Practice:** Visualize Titanic/Iris dataset

### Day 10: Exploratory Data Analysis (EDA)

- EDA workflow and checklist
- Statistical summaries, correlations
- Identifying outliers and patterns
- **Practice:** Full EDA on a chosen dataset

---

## Week 3: Machine Learning Foundations (Days 11–16)

### Day 11: Introduction to Machine Learning

- What is ML? Types: supervised, unsupervised, reinforcement
- Scikit-learn overview
- Train/test split, model evaluation basics
- **Practice:** First ML model (linear regression on toy data)

### Day 12: Linear Regression & Polynomial Regression

- Simple & multiple linear regression
- Cost function, gradient descent (conceptual)
- Polynomial features, overfitting/underfitting
- **Practice:** House price prediction

### Day 13: Classification — Logistic Regression & KNN

- Logistic regression (binary classification)
- K-Nearest Neighbors
- Confusion matrix, accuracy, precision, recall, F1
- **Practice:** Iris species classification

### Day 14: Decision Trees & Random Forests

- Decision tree algorithm, entropy, information gain
- Random forest (ensemble methods)
- Feature importance
- **Practice:** Customer churn prediction

### Day 15: Model Evaluation & Tuning

- Cross-validation (k-fold)
- Hyperparameter tuning (GridSearchCV)
- Bias-variance tradeoff
- ROC curve, AUC
- **Practice:** Tune a Random Forest model

### Day 16: Unsupervised Learning & Feature Engineering

- K-Means clustering
- PCA (dimensionality reduction)
- Feature scaling, encoding categorical variables
- Feature selection techniques
- **Practice:** Customer segmentation

---

## Week 4: Capstone Project (Days 17–20)

### Capstone Project: End-to-End ML Pipeline

**Problem:** Predict loan approval (or similar real-world classification problem)

### Day 17: Problem Definition & Data Collection

- Define problem statement and success metrics
- Acquire and load dataset
- Initial EDA: distributions, missing values, correlations
- Document findings and plan preprocessing steps

### Day 18: Data Preprocessing & Feature Engineering

- Handle missing values, outliers
- Encode categorical features
- Feature creation and selection
- Prepare final train/test datasets

### Day 19: Model Building & Evaluation

- Train multiple models (Logistic Regression, Random Forest, etc.)
- Compare using cross-validation
- Hyperparameter tuning on best model
- Final evaluation on test set

### Day 20: Presentation & Deployment Intro

- Create a clean Jupyter Notebook report
- Summarize results with visualizations
- Brief intro to model saving (pickle/joblib)
- Brief intro to deployment (Flask API or Streamlit demo)
- **Student presentations**

---

## Tools & Libraries

Python 3.x, Jupyter Notebook, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
